# Django Blog Project

این پروژه یک وبلاگ ساده با Django است که به عنوان تمرین جلسات آموزشی ساخته شده است.

## امکانات پروژه
- ساخت مدل `Post`
- تعیین وضعیت پست‌ها به صورت `Draft` و `Published`
- مدیریت پست‌ها از طریق پنل ادمین Django
- نمایش لیست پست‌های منتشرشده
- نمایش صفحه جزئیات هر پست
- استفاده از قالب‌های HTML
- استایل‌دهی ساده با CSS

## چیزهایی که در این پروژه یاد گرفتم
- ساخت پروژه و اپ در Django
- کار با مدل‌ها
- ثبت مدل در پنل ادمین
- تعریف URL
- نوشتن View
- کار با Template
- اضافه کردن فایل‌های static
